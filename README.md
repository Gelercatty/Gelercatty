# Hi, I'm Yanwen Ma 👋

You can also call me **Geler (格尔)**.

I'm a **CS graduate student at Beihang University**, currently interning with the **[Echo Team](https://github.com/Echo-Team-Joy-Future-Academy-JD) at JD Explore Academy**.

I also work part-time as a **Technical Artist at [SentNet](https://sentnet.top/)**, mostly working on making things look better :)
